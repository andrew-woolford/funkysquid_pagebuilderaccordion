# Accordion module for Page Builder.

Introducing the Funky Squids Adobe Page Builder pure HTML & CSS accordion, an elegant and efficient solution for displaying content in a compact and interactive manner.

This accordion component, designed for seamless integration with Adobe Commerce (Magento) Page Builder, allows you to organise and present information in expandable and collapsable sections.

Each section can be opened and closed by clicking the accompanying open/close arrows, providing a clean and user-friendly experience without the need for JavaScript.

## Key features:
- **Pure HTML & CSS Implementation:**
  - Built entirely with HTML & CSS, this accordion ensures fast performance and compatibility across all modern browsers.
- **Interactive Text Areas:**
  - Each accordion section contains a text area that can be expanded or collapsed, allowing users to reveal or hide content as needed.
- **Responsive Design:**
  - The accordion is fully responsive, adapting smoothly to different screen sizes and devices, ensuring an optimal viewing experience on desktops, tablets, and mobile devices.
- **Easy Integration:**
  - Specifically designed for Adobe Page Builder, this accordion can be effortlessly added to your page layouts, enhancing your content presentation.
- **Customisable Styles:**
  - Easily modify the appearance of the accordion to match your site’s branding and style preferences with straightforward CSS adjustments.

## Benefits:
- **Faster Page Loads:** 
  - A pure-HTML & CSS implementation means no JavaScript library overhead, keeping the accordion fast and lightweight.
- **Improved Readability:** 
  - Collapsing secondary content reduces visual clutter, letting visitors scan a page and open only what’s relevant to them.
- **Broad Compatibility:**
  - Built entirely with CSS, the accordion works consistently across modern browsers without relying on JS support.
- **Consistent Brand Presentation:**
  - Customisable styling keeps the accordion on-brand with the rest of your site’s design.
- **Space-Efficient Content:**
  - Detailed information, FAQs, specs, descriptions, can be included in full without lengthening the page for visitors who don’t need it.

## Configuration:
- Navigate to the Page Builder interface in your admin panel.
- Drag and drop the HTML Accordion element onto your page.
- Add a section via the repeater, enter the section title, and add the content for the expandable text area.
- Repeat for each additional section; the accordion updates automatically to include every entry.
- Save; sections can be opened and closed independently using the open/close arrows; no JavaScript required.

## Use Cases:

- **Content Organisation:**

  - Offer detailed product specifications, descriptions, and other information in expandable sections to save space and improve readability.
